## Embedded / depended-upon libraries

### Ketcher
- **Role:** Embedded web-based molecular structure editor (draw starting materials, intermediates, products; export MOL/SMILES/RXN). The curved electron-pushing arrow layer is a MechGrader overlay on top (arrows stored as atom/bond-id tuples).
- **Upstream:** https://github.com/epam/ketcher
- **Copyright:** © EPAM Systems, Inc.
- **License:** **Apache License 2.0.**
- **Verified:** 2026-07-05 via the GitHub repository metadata, `LICENSE`, `NOTICE`, and the project site (https://lifescience.opensource.epam.com/ketcher/). Latest release observed: v3.12.0 (2026-03-04).
- **AGPL compatibility:** Apache-2.0 is one-way compatible with (A)GPL-3.0 — Apache-2.0 code may be combined into an AGPL-3.0 work. We keep Ketcher's Apache-2.0 `LICENSE` and `NOTICE` with any redistributed Ketcher assets.

### RDKit (Python `rdkit`) and RDKit-JS / `@rdkit/rdkit` (WASM)
- **Role:** Cheminformatics engine for honest grading: canonical SMILES, InChIKey, valence/charge validation, substructure (SMARTS) matching, Morgan fingerprints (dedup/leakage). Python on desktop; RDKit-JS/WASM in the webview for offline/client-side checks.
- **Upstream:** https://github.com/rdkit/rdkit  ·  https://github.com/rdkit/rdkit-js
- **Copyright:** © Greg Landrum and other RDKit contributors.
- **License:** **BSD 3-Clause ("New"/"Revised").**
- **Verified:** 2026-07-05 via the GitHub repository metadata and `README.md`/`license.txt`. Latest release observed: 2026.03 (Q1 2026).
- **Vendored:** `@rdkit/rdkit` **2025.3.4** (`RDKit_minimal.js` + `RDKit_minimal.wasm`) committed under `web/mechgrader/vendor/rdkit/` so the editor loads RDKit-JS offline (no CDN). BSD-3-Clause.
- **Honest license nuance:** RDKit is overwhelmingly BSD-3-Clause, but a small number of files carry other permissive licenses (e.g. `rdkit/Chem/MCS.py`, `fmcs.py`, `EEM.*` under BSD-2-Clause; `six.py` under MIT; `ullmann.hpp` under BSL-1.0). The SMILES/SMARTS parser files generated by GNU Bison (`*.tab.*`) contain a GPL header **with the standard Bison runtime exception**, which explicitly permits distributing the generated output under a license of your choice; they are therefore not GPL-restricting. All of the above are compatible with AGPL-3.0-or-later.

## How to regenerate / audit

- Anki's own dependency license inventory is produced by `just minilints` /
  `ninja check:minilints` (Rust/JS/Python dependency licenses).
- Re-verify Ketcher/RDKit versions and licenses against the exact versions you
  vendor before any release, and copy their upstream `LICENSE`/`NOTICE` files
  next to the vendored artifacts.
